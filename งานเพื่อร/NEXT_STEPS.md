# จากตัวนับสู่ Random Forest

## อัปเดต: ฝึกโดยไม่ย้ายหรือเปลี่ยนชื่อ CSV
โปรแกรมค้นหา attempts_to_label.csv ที่ติด label ครบแล้วใน runs ให้เอง
เลือกหนึ่งผลต่อวิดีโอ โดยใช้ผลที่ตรวจครบล่าสุด ข้ามผลรันซ้ำที่ยังไม่ได้ติด label
เก็บ split=train/test ตามที่คนกำหนด ไม่ย้ายคลิปทดสอบเข้าฝึก
หากคลิปเดียวกันถูกกำหนด train/test ขัดกันในหลายไฟล์ โปรแกรมจะหยุดให้แก้ก่อน

ดูรายการที่จะใช้โดยยังไม่ฝึก:
```powershell
.\train_forest.ps1 --list-data --test-videos 814201997.884944
```
ฝึกโดยรวมคลิป train เดิมและใหม่ และใช้เฉพาะคลิปทดสอบใหม่ที่ระบุ:
```powershell
.\train_forest.ps1 --test-videos 814201997.884944
```
เลือกชื่อโฟลเดอร์โมเดลเวอร์ชันถัดไปให้เอง ไม่ทับโมเดลเดิม
ถ้าต้องการระบุชื่อเอง เพิ่ม --out models/random_forest_v3
ถ้าไม่ระบุ --test-videos โปรแกรมจะใช้คลิป test ที่ตรวจครบทั้งหมด โดยไม่มีการย้ายเข้า train
ทุกโมเดลใหม่มี dataset_sources.json ระบุไฟล์ต้นทางและเหตุผลที่ข้ามไฟล์อื่น
หากต้องการเลือกไฟล์เองแบบเดิม ใช้ --choose-files หรือ --data ตามด้วยตำแหน่ง CSV

## ตอนนี้ทำขั้นเดียวก่อน: ติด label คลิปล่าสุด
ใน Terminal โฟลเดอร์ buta-progress2:
```powershell
.\review_labels.ps1
```
เลือก attempts_to_label.csv ในหน้าต่างที่เปิดมา (เริ่มที่โฟลเดอร์ผลล่าสุด)
โปรแกรมวนแสดงช่วงการเคลื่อนไหวให้ดูทีละช่วง พร้อมเริ่ม/จบเป็นวินาที
- P = ผ่านเกณฑ์ที่คุณตรวจ
- D = ไม่ผ่านเรื่องความลึกตามเกณฑ์ที่กำหนด
- R = ไม่ผ่านเรื่องกลับขึ้นไม่ครบตามเกณฑ์ที่กำหนด
- F = ไม่ผ่านเรื่องฟอร์มอื่นที่คุณตรวจพบ (เพิ่มรายละเอียด reason ใน CSV ภายหลังได้)
- U = ดูไม่ชัดหรือแบ่งช่วงผิด ยังตัดสินไม่ได้
- N / B = ไปช่วงถัดไป / ย้อนกลับ
- Space = พัก / เล่นต่อ, Q = บันทึกและออก

เลือก label จากการตรวจคลิปตามเกณฑ์ที่กำหนด ไม่ใช้เลขตัวนับเป็นเฉลย
ก่อนติดจริง ให้เขียนเกณฑ์ของโครงการให้คงที่ ถ้าตัดสินไม่ได้ให้ U อย่าเดา
ไฟล์มีสำเนาก่อนแก้ .csv.original และบันทึก label ทุกครั้งที่กด
หมายเลข attempt เป็นช่วงที่ตรวจเจอ อาจไม่ตรงจำนวนครั้งจริงหากภาพขาดหรือแบ่งผิด
หากหนึ่งช่วงครอบคลุมหลาย rep หรือครึ่ง rep ให้ U แล้วตรวจการแบ่งช่วงก่อน ไม่ฝืนติด label

## 1. สร้างข้อมูลจากคลิปอื่น
```powershell
.\start_counter.ps1 --person-id P01
```
เลือกคลิปด้านข้าง ภาพชัด ใช้กางเกงและระยะกล้องที่ทดลองแล้วจับจุดต่อเนื่อง
ผลใหม่อยู่ใน runs/<ชื่อคลิป>_<เวลา>/attempts_to_label.csv
ทุกแถวมีมุมเข่าต่ำสุด มุมกลับขึ้นที่เห็นภายในช่วง ระยะเวลา มุมสะโพกต่ำสุด และแนวลำตัวสูงสุด
ช่วงที่ tracking หาย/คลิปจบกลางรอบจะเก็บไว้ตรวจ และข้ามในการฝึกโดยอัตโนมัติ
ค่ามุมลำตัวไม่ได้วัดความโค้งของกระดูกสันหลังโดยตรง จึงยังอ้างว่าตรวจหลังงอได้เฉพาะเจาะจงไม่ได้

## 2. กำหนดชุดฝึกและทดสอบก่อนดูผลโมเดล
คลิปสำหรับฝึก ใช้ review_labels.ps1 ตามปกติ (split=train)
คลิปใหม่ที่กันไว้ทดสอบ ใช้:
```powershell
.\review_labels.ps1 --split test
```
ทั้งคลิปต้องอยู่ชุดเดียวกัน อย่านำคลิปทดสอบมาฝึกหรือปรับโมเดลตามผลซ้ำ ๆ
ถ้ามีหลายคน ให้กันคนทดสอบออกจากชุดฝึกด้วย โปรแกรมจะตรวจการทับซ้อนให้
ถ้ามีคนเดียว โปรแกรมอนุญาตทดสอบแยกคลิป แต่ต้องรายงานว่าเป็นการทดลองกับคนเดียว
ชุดฝึกต้องมีทั้ง pass และ fail ที่คนตรวจจริง ถ้าทั้งหมด pass ยังฝึกตัวแยกสองกลุ่มไม่ได้
จำนวนข้อมูลน้อยใช้ทดลองกระบวนการได้ ยังไม่รับประกันความแม่นยำกับคนทั่วไป

## 3. ฝึก Random Forest
```powershell
.\train_forest.ps1
```
เลือก CSV ที่ตรวจแล้วทั้ง train และ test พร้อมกัน เลือกเพียงหนึ่งผลต่อวิดีโอ ห้ามเลือกสำเนารันซ้ำ
ผลอยู่ใน models/random_forest/:
- model.joblib: โมเดลและขั้นตอนจัดการค่าขาดหาย
- metrics.json: confusion matrix, precision/recall/F1 รายกลุ่ม และ accuracy ของคลิปทดสอบ
- test_predictions.csv: คำตอบจริงเทียบคำทำนายรายช่วง
- data_used.csv: ข้อมูลที่ใช้ในรอบฝึกนี้เพื่อย้อนตรวจ

โปรแกรมไม่ฝึกหากไม่มี label, มีเพียงคลาสเดียว หรือใช้วิดีโอเดียวกันทั้ง train/test
โปรแกรมเปรียบเทียบกับ baseline ที่ทายคลาสส่วนใหญ่เสมอด้วย
หากฝึกรอบใหม่ ต้องเลือก --out โฟลเดอร์ใหม่ เช่น models/random_forest_v2 เพื่อไม่ทับผลเดิม
RF เรียนรู้ pass/fail เท่านั้น ไม่ได้เรียนคำอธิบาย reason ในรุ่นนี้
หาก label เกิดจากกฎองศาอย่างเดียว ผลโมเดลคือการเลียนแบบกฎนั้น ควรรายงานตามจริง

## 4. ต่อโมเดลขึ้นหน้าจอ
หลังมีโมเดลที่ฝึกจาก label จริงแล้ว:
```powershell
.\start_counter.ps1 --rf-model models/random_forest/model.joblib
```
เมื่อจบช่วง ระบบจะแสดง RF: pass / fail; ข้อมูลที่หายจะแสดง Unassessable
ยังไม่บอกสาเหตุหลังงอหรือความเสี่ยงบาดเจ็บจากผล pass/fail อย่างเดียว
ใช้เฉพาะโมเดล joblib ที่สร้างจากโค้ดนี้เอง

## เงื่อนไขตัวนับรุ่นใหม่
- มุมย่อเริ่มต้น <=120 องศา กลับขึ้น >=150 องศา เป็นค่าทดลองแบ่งการเคลื่อนไหว ไม่ใช่เกณฑ์ฟอร์ม
- ต้องเห็นค่าถึงเกณฑ์ต่อเนื่องอย่างน้อย 0.10 วินาที ลดผลจากเฟรมกระโดด
- เริ่มช่วงเมื่อมุมต่ำกว่าเกณฑ์ยืน 8 องศา ลดการสั่นแถวจุดยืน
- รอบที่นับต้องยาวอย่างน้อย 0.6 วินาที
- จุดหายไม่เกิน 0.25 วินาทีเก็บสถานะไว้ หากนานกว่านั้นปิดช่วงเป็น tracking_lost และรอยืนใหม่
- เก็บการเคลื่อนไหวตื้น/กลับไม่สุดบางรูปแบบไว้ใน attempts_to_label.csv ไม่ใช่ทิ้งทั้งหมด
- การแบ่งช่วงยังเป็นต้นแบบ ต้องตรวจเทียบคลิปจริง ไม่รับประกันว่าตรวจพบทุกความพยายาม
